## 📖 About The Project

**TaskPulse** is a modern, responsive task management hub built with **React** and **Bootstrap 5**. It is designed to adapt seamlessly to different workflows—whether you are a student tracking assignments, a professional managing project stages, or someone organizing daily personal tasks.

By focusing on predictable user experience, smooth responsiveness, and local data persistence, TaskPulse delivers a clean workspace experience without needing a backend server.

---

## 🌟 Key Features

* **🎓 Persona-Based Onboarding:** Custom workspace templates (*Student / Academic*, *Office & Professional*, or *Personal & Life*) automatically set up relevant stage columns and starter tasks upon first visit.
* **✅ Task & Subtask Progress:** Break complex tasks into nested checklists with dynamic percentage progress bar tracking.
* **🏷️ Stage & Priority Management:** Add, edit, organize, and move tasks across workspace columns using an intuitive modal interface.
* **🌙 Light / Dark Mode Engine:** Dynamic theme switcher powered by native Bootstrap color modes and persistent theme storage.
* **💾 Local Storage Sync:** Saves your workspace state automatically so your tasks and preferences persist across browser sessions.
* **📦 JSON Backup & Restore:** Export your full workspace (tasks, profile, columns, and team members) to a `.json` file and import it back anytime.
* **📱 Mobile-First Responsive Design:** Fully optimized header and layout for smooth usage across mobile devices, tablets, and desktop screens.

## 🛠️ Tech Stack

* **Frontend Framework:** React.js
* **UI & Styling:** Bootstrap 5, Bootstrap Icons, Custom CSS
* **Icons:** Bootstrap Icons (`bi`)
* **State Management:** React Hooks (`useState`, `useEffect`) & Web Storage API (`localStorage`)
* **Deployment:** Vercel

## 🚀 Getting Started Locally

To run TaskPulse locally on your machine, follow these steps:

### 1. Prerequisites
Ensure you have **Node.js** (v14 or higher) installed.

### 2. Clone the Repository
```bash
git clone [https://github.com/YOUR-USERNAME/taskpulse.git](https://github.com/YOUR-USERNAME/taskpulse.git)
cd taskpulse
```
### 3. Install Dependencies
   ```  
     npm install
   ```
4. Start the Development Server
     npm run dev
      # or
     npm start
   
Open your browser and navigate to http://localhost:5173
