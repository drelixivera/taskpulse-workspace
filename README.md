# ⚡ TaskPulse — Workspace & Task Management Hub

**TaskPulse** is a responsive, feature-packed task management application built with React and Bootstrap. Designed to cater to students, office workers, and everyday users, TaskPulse personalizes your workspace based on your unique workflow.

---

## 🌟 Key Features

* **🎓 Personalized Persona Onboarding:** Select your persona (*Student / Academic*, *Office & Professional*, or *Personal & Life*) during initial launch to auto-generate customized column templates and starter tasks.
* **✅ Task & Subtask Management:** Break down complex tasks into nested checklists with real-time progress bar tracking.
* **🏷️ Stage & Priority Control:** Easily create, edit, categorize, and shift tasks across columns using a smooth modal interface.
* **🌙 Dark / Light Mode Engine:** Full theme-switching support powered by dynamic Bootstrap color modes.
* **💾 Local Data Persistence:** Keeps your workspace state saved across browser sessions using `localStorage`.
* **📦 JSON Backup & Restore:** Export your entire workspace (user profile, tasks, columns, and team members) to a `.json` file and restore it anytime.
* **📱 Responsive Layout:** Built mobile-first to ensure seamless usage across phones, tablets, and desktops.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Hooks & Context)
* **Styling:** Bootstrap 5, Bootstrap Icons, Custom CSS
* **Build Tool:** Vite / Create React App
* **State Management:** LocalStorage API & React State
